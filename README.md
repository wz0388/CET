# CET 六级听力练习站

一个自己用的英语六级备考站点：把真题听力切成小段做精听，配合背单词、云端进度和多端同步。纯 PHP + 原生 JS，没有构建步骤，扔进任意支持 PHP 8 的空间就能跑。

## 功能

### 听力练习（`practice.php`）
- 按「一段音频」切分（长对话 / 篇章 / 讲座），每段 3–4 题
- 可循环播放本段、单题音频、显示原文（ASR 转写）、隐藏选项专注精听
- **按段批改**：本段题目全部答完才统一批改，中途不显示对错；改完后选项锁定，可一键「重做本段」
- 考试模式（`exam.php`）：整卷连播、倒计时、交卷出分

### 背单词（`words.php`）
- 词库：CET-6 核心词汇 2345 个（音标 + 中文释义 + 例句 + 短语 + 近义词）
- **打字记忆**：给中文释义，敲出英文；打错必须退格改正
- **四遍记忆阶梯**，每个词独立记录进度：

  | 阶段 | 提示 | 音标 | 原词 | 例句 | 发音 |
  |---|---|---|---|---|---|
  | 第 1 遍 · 跟打 | 中文 | ✓ | ✓ | ✓ | ✓ |
  | 第 2 遍 · 例句挖空 | 中文 | ✓ | ✗ | ✓（挖空） | ✓ |
  | 第 3 遍 · 只听发音 | 中文 | ✗ | ✗ | ✗ | ✓ |
  | 第 4 遍 · 只看中文 | 中文 | ✗ | ✗ | ✗ | ✗ |

  一遍全对才进下一遍；打错或跳过则该遍作废，排到本轮末尾重来
- 按住 `Tab` 看提示：首次不判错，第二次看即作废
- 虚拟键盘（仅第 1 遍高亮下一个该按的键）、逐字对错音效、连击提示
- `\` 加入收藏本，`/` 加入熟悉本（纯手动维护），错词答错自动进错词本
- `'` 唤出联网搜词：本地词库 + 有道联想，可查任意单词的音标/释义/例句
- 右侧词典栏实时展示上一个词的完整词条；最右侧「云端进度」列出最近 10 条练习记录

### 账号与后台
- 登录/注册由后台统一创建账号，管理员可批量建号、重置密码、停用、查看答题与访问记录
- 密码修改后**其它设备上的会话立即失效**
- 登录失败次数限制、后台操作日志、仅境内可访问

## 部署

1. PHP 8.1+、MySQL 5.7+ / 8.0，站点根目录指向 `site/`
2. 复制 `site/config.example.php` 为 `site/config.php`，填数据库信息和自己想要的初始管理员密码
3. 首次访问会自动建表，并用 `SEED_ADMIN_USER` / `SEED_ADMIN_PASS` 写入管理员（仅当 users 表为空）
4. `site/data/` 需要可写（缓存目录 `data/cache/` 会自动创建）
5. 听力音频不随仓库提供，放到 `site/audio/set1.mp3`、`set2.mp3`（`papers.json` 里引用的路径）

## 数据来源

- 真题与听力原文：历年六级真题（仅用于个人备考，版权归原出版方）
- 词库：基于开源词库 [qwerty-learner](https://github.com/RealKai42/qwerty-learner) 的 CET6 词表整理，释义/例句/发音由有道词典接口实时获取（`build_words.py` 可重新生成 `data/cet6.json`）
- 交互参考：[TypeWords](https://github.com/zyronon/TypeWords) 的打字记忆思路
